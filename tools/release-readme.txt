Oblachko: перевод манги прямо в браузере
========================================

Что нужно
---------
- Windows, видеокарта NVIDIA (от 8 ГБ).
- Google Chrome.
- LM Studio: https://lmstudio.ai
- uv (ставит Python и библиотеки сам). Один раз выполните в PowerShell:
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Установка (один раз)
--------------------
1. Распакуйте архив в постоянное место, например C:\Oblachko.
   Не удаляйте и не переносите папку потом: Chrome загружает расширение из неё.

2. LM Studio:
   - скачайте модель (проверены google/gemma-4-12b-qat и qwen3.5-9b);
   - вкладка Developer: загрузите модель, поставьте Context Length 4096, нажмите Start Server;
   - если порт не 1234, после первого запуска start.bat поправьте llm_base_url в server\config.toml.

3. Запустите start.bat. Первый раз он скачает всё нужное (несколько ГБ, 5-15 минут).
   Когда появится "Uvicorn running on http://127.0.0.1:8765", сервер готов.

4. Chrome: откройте chrome://extensions, включите "Режим разработчика" (справа вверху),
   нажмите "Загрузить распакованное расширение" и выберите папку extension внутри Oblachko.

Каждый раз
----------
1. Запустите LM Studio с сервером.
2. Запустите start.bat и не закрывайте его окно.
3. Откройте главу манги, нажмите на иконку Oblachko и включите "Переводить на этом сайте".
   Зажмите Alt, чтобы увидеть оригинал.

Обновления
----------
start.bat при каждом запуске сам проверяет новую версию, скачивает её и обновляет и сервер,
и расширение. Chrome подхватит новое расширение сам. Ваши настройки, модели и имена персонажей
сохраняются.

Если что-то не работает
-----------------------
- Красный "!" на странице: наведите на него или откройте попап расширения, там текст ошибки.
- "Сервер не отвечает": не запущен start.bat.
- "LLM недоступна": не запущен сервер в LM Studio или неверный порт в server\config.toml.
